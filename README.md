# 단어정원

엑셀 단어장을 올려 하루 10분씩 영어 단어를 익히는 웹앱입니다. 아이폰 홈 화면에 추가해 앱처럼 쓰고, 구글 시트로 가족의 단어장과 학습 기록을 함께 관리합니다.

- 학습 방식: 떠올리기 퀴즈(뜻 고르기 → 듣고 고르기 → 예문 빈칸 → 글자 조합 → 철자 입력)와 간격 반복(1·3·7·14·30·60일)
- 흥미 요소: 연속 학습일, 레벨과 XP, 단어 성장 6단계, 배지 20종, 미니게임 2종, 형제 주간 대결
- 저장: 각 기기에 저장하고, 연결하면 구글 시트에 자동 백업

## 설치 순서

### 1단계. 웹사이트 켜기 (GitHub Pages, 1회)

1. GitHub에서 이 저장소의 **Settings → Pages**로 들어갑니다.
2. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 같은 화면 위쪽에 표시되는 주소(`https://<계정>.github.io/<저장소 이름>/`)가 앱 주소입니다.

### 2단계. 구글 시트 연결 만들기 (부모님, 1회, 약 10분)

1. PC에서 <https://sheets.new> 를 열어 새 시트를 만들고 이름을 `단어정원`으로 바꿉니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 기존 코드를 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 전부 붙여 넣은 뒤 저장합니다.
4. 위쪽 함수 선택 칸에서 `setup`을 고르고 **실행**을 누릅니다. 권한 요청이 나오면 **권한 검토 → 계정 선택 → 고급 → (프로젝트 이름)(으)로 이동 → 허용** 순서로 진행합니다. 본인이 만든 스크립트라 표시되는 경고이며, 이 스크립트는 이 시트만 읽고 씁니다.
5. 오른쪽 위 **배포 → 새 배포**를 누르고, 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다. 이 주소가 **연결 코드**입니다.

연결 코드를 아는 사람은 이 시트의 단어장과 학습 기록을 읽고 쓸 수 있습니다. 가족에게만 전달하세요.

나중에 `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 주소는 그대로 유지됩니다.

### 3단계. 아이폰에 설치 (기기마다 1회)

1. 아이폰 **사파리**에서 1단계의 앱 주소를 엽니다.
2. 아래쪽 **공유 버튼 → 홈 화면에 추가**를 누릅니다.
3. 홈 화면에 생긴 **단어정원 아이콘**으로 앱을 엽니다. 사파리와 홈 화면 앱은 저장 공간이 서로 다르므로, 프로필은 반드시 이 아이콘으로 연 화면에서 만드세요.
4. 이름, 캐릭터, 학년을 고르고 시작합니다.
5. **내 정보 → 가족 연결**에 연결 코드를 붙여 넣고 **연결하기**를 누릅니다. 카카오톡이나 메모로 코드를 보내 두면 붙여 넣기 편합니다.

두 아이가 각자 폰에서 같은 연결 코드를 넣으면 단어장이 함께 보이고 주간 대결이 시작됩니다.

## 단어장 올리는 방법

엑셀 형식은 아래와 같습니다. 첫 줄 제목은 있어도 되고 없어도 됩니다. 앞에 번호 열이 있어도 자동으로 건너뜁니다.

| A열 | B열 | C열 (선택) | D열 (선택) |
|---|---|---|---|
| 단어 | 뜻 | 예문 | 예문 해석 |
| borrow | 빌리다 | Can I borrow your pen? | 네 펜을 빌려도 될까? |

- **앱에서 올리기**: 단어장 탭 → 엑셀 파일 올리기. 파일 하나가 단어장 하나가 되고, 시트가 여러 개면 시트마다 단어장이 됩니다. `.xlsx`, `.xls`, `.csv`를 지원합니다. PC 브라우저에서 앱 주소를 열어 올려도 됩니다.
- **구글 시트에 직접 넣기**: `단어정원` 시트에 새 탭을 만들고 같은 형식으로 붙여 넣으면, 탭 이름이 단어장 이름이 됩니다. 앱을 다시 열거나 **지금 동기화**를 누르면 나타납니다.

예문이 있는 단어장에서는 예문 빈칸 문제가 추가로 나옵니다. `samples` 폴더에 두 가지 형식의 예시 파일이 있습니다.

## 구글 시트에서 볼 수 있는 것

| 탭 | 내용 |
|---|---|
| (단어장 이름) | 단어장 내용. 직접 고쳐도 됩니다. |
| `_프로필` | 아이별 레벨, 총 XP, 이번 주 XP, 연속 학습일, 배운 단어 수, 마스터 단어 수, 정답률, 마지막 학습일 |
| `_학습기록` | 학습할 때마다 한 줄씩: 일시, 이름, 단어장, 종류, 문제 수, 정답 수, XP, 소요 시간 |
| `_주간기록` | 주간 대결 점수 |
| `_백업` | 기기 변경에 대비한 학습 진행 백업. 고치지 마세요. |

`_`로 시작하는 탭은 앱이 관리하므로 이름을 바꾸거나 지우지 마세요.

## 자주 묻는 것

- **폰을 바꿨어요.** 새 폰에서 앱을 열고 첫 화면의 **이전 기록 불러오기**에 연결 코드를 넣으면 프로필을 그대로 가져옵니다.
- **발음이 안 들려요.** 아이폰 음량과 무음 스위치를 확인하세요. 발음은 아이폰에 내장된 영어 음성을 씁니다.
- **인터넷이 안 될 때는?** 이미 받아 둔 단어장으로 학습할 수 있고, 다시 연결되면 기록이 올라갑니다. 단, 앱을 처음 여는 순간에는 인터넷이 필요합니다.
- **학습 도중에 나가면?** 그 회차는 저장되지 않습니다. 한 회차는 10분 안팎입니다.
